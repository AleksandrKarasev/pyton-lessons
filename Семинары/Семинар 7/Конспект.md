## Задание 2

Задача Nº49. Решение задачи
Планеты вращаются вокруг звезд по эллиптическим орбитам.
Назовем самой далекой планетой ту, 
орбита которой имеет самую большую площадь. 
Напишите функцию find_farthest_orbit(list_of_orbits), 
которая среди списка орбит планет найдет ту, 
по которой вращается самая далекая планета. 
Круговые орбиты не учитывайте: 
вы знаете, что у вашей звезды таких планет нет, 
зато искусственные спутники были были запущены на круговые орбиты. 
Результатом функции должен быть кортеж, 
содержащий длины полуосей эллипса орбиты самой далекой планеты. 
Каждая орбита представляет из себя кортеж из пары чисел - полуосей ее эллипса. 
Площадь эллипса вычисляется по формуле S = pi*a*b, где а и b - длины полуосей эллипса. 
При решении задачи используйте списочные выражения. 
Подсказка: проще всего будет найти эллипс в два шага: 
сначала вычислить самую большую площадь эллипса, 
а затем найти и сам эллипс, имеющий такую площадь. 
Гарантируется, что самая далекая планета ровно одна

### Решение 

### Код
```py
def find_farthest_orbit(list_of_orbits):
    # 1. Отбираем только эллиптические орбиты (не круговые)
    elliptical_orbits = [orbit for orbit in list_of_orbits if orbit[0] != orbit[1]]
    
    # 2. Вычисляем произведения полуосей (пропорционально площади)
    areas = [a * b for a, b in elliptical_orbits]
    
    # 3. Находим максимальную площадь
    max_area = max(areas)
    
    # 4. Находим орбиту с такой площадью (гарантированно одна)
    index = areas.index(max_area)
    return elliptical_orbits[index]


# Пример использования
orbits = [(1, 3), (2.5, 10), (7, 2), (6, 6), (4, 3)]
print(find_farthest_orbit(orbits))  # Ожидаемый результат: (2.5, 10)
```

## Задание 3

Задача Nº51. Решение задачи
Напишите функцию same_by(characteristic, objects), которая проверяет, 
все ли объекты имеют одинаковое значение некоторой характеристики, 
и возвращают True, если это так.
Если значение характеристики для разных объектов отличается - то False. 
Для пустого набора объектов, функция должна возвращать True. 
Аргумент characteristic - это функция, которая принимает объект 
и вычисляет его характеристику.
Ввод:
Вывод:
values = [0, 2, 10, 6]
same
if same_by(lambda x: x % 2, values):
print('same')
else:
print('different')

### Решение 

### Код
```py
def same_by(characteristic, objects):
    """
    Проверяет, все ли объекты имеют одинаковое значение характеристики.
    
    Args:
        characteristic: функция, принимающая объект и возвращающая его характеристику.
        objects: итерируемый объект (список, кортеж и т.д.).
        
    Returns:
        True, если все характеристики одинаковы или список пуст, иначе False.
    """
    # Создаём множество уникальных характеристик
    unique = {characteristic(obj) for obj in objects}
    # Если характеристик не более одной, возвращаем True
    return len(unique) <= 1


# Демонстрация из условия задачи
values = [0, 2, 10, 6]
if same_by(lambda x: x % 2, values):
    print('same')
else:
    print('different')

# Дополнительная проверка для пустого списка
print(same_by(lambda x: x % 2, []))  # True
```

## Задание 1

Задача 34: Винни-Пух попросил Вас посмотреть, есть ли в его стихах ритм. 
Поскольку разобраться в его кричалках не настолько просто, насколько легко 
он их придумывает, Вам стоит написать программу. 
Винни-Пух считает, что ритм есть, если число слогов 
(т.е. число гласных букв) в каждой фразе стихотворения одинаковое. 
Фраза может состоять из одного слова, если во фразе несколько слов, 
то они разделяются дефисами. Фразы отделяются друг от друга пробелами. 
Стихотворение Винни-Пух вбивает в программу с клавиатуры. 
В ответе напишите "Парам пам-пам", если с ритмом все в порядке и "Пам парам",
если с ритмом все не в порядке

### Решение 

### Код

```py
def count_vowels(phrase):
    """Подсчитывает количество гласных букв в фразе."""
    vowels = "аеёиоуыэюя"
    return sum(1 for char in phrase.lower() if char in vowels)

def check_rhythm(poem):
    """
    Проверяет, есть ли ритм в стихотворении Винни-Пуха.
    Возвращает "Парам пам-пам", если количество гласных во всех фразах одинаково,
    иначе "Пам парам".
    """
    phrases = poem.split()  # фразы разделены пробелами
    if not phrases:
        return "Парам пам-пам"  # пустое стихотворение — ритм есть

    # Вычисляем количество гласных в каждой фразе
    vowels_counts = [count_vowels(phrase) for phrase in phrases]

    # Проверяем, все ли значения одинаковы
    if all(count == vowels_counts[0] for count in vowels_counts):
        return "Парам пам-пам"
    else:
        return "Пам парам"

# Ввод стихотворения с клавиатуры и вывод результата
poem_input = input("Введите стихотворение Винни-Пуха: ")
result = check_rhythm(poem_input)
print(result)
```

## Задание 2

Задача 36: Напишите функцию print_operation_table(operation, 
num_rows=6, num_columns=6),
которая принимает в качестве аргумента функцию, 
вычисляющую элемент по номеру строки и столбца. 
Аргументы num_rows и num_columns указывают число строк 
и столбцов таблицы, которые должны быть распечатаны. 
Нумерация строк и столбцов идет с единицы (подумайте, почему не с нуля). 
Примечание: бинарной операцией называется любая операция, у
 которой ровно два аргумента, как, например, у операции умножения.

### Решение 

### Код
```py
def print_operation_table(operation, num_rows=6, num_columns=6):
    """
    Печатает таблицу из num_rows строк и num_columns столбцов,
    где элемент на позиции (i, j) вычисляется как operation(i, j).
    Нумерация строк и столбцов начинается с 1.
    """
    # Собираем все элементы таблицы, чтобы определить нужную ширину столбца
    table = []
    for row in range(1, num_rows + 1):
        row_values = []
        for col in range(1, num_columns + 1):
            row_values.append(operation(row, col))
        table.append(row_values)

    # Максимальная длина строкового представления элемента
    max_width = max(len(str(val)) for row in table for val in row) if table else 0

    # Печать таблицы с выравниванием по правому краю
    for row in table:
        for val in row:
            print(f"{val:>{max_width}}", end=" ")
        print()  # переход на новую строку

# Пример использования:
print_operation_table(lambda x, y: x + y)
```
