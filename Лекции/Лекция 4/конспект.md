### Задача 
В списке хранится числа. Нужно выбрать только четные числа и составить список пар

```py
data = [1, 2, 3,5,8,15, 23,38]
res = list()
for i in data:
    if i%2==0:
        res.append((i,i**2))
print(res)
```

#### Решение через lambda - функцию

```py
def select(f,col):
    return [f(x) for x in col]

def where (f,col):
    return[x for x in col if f(x)]

data = [1, 2, 3,5,8,15, 23,38]

res=select(int, data)

res=where(lambda x : x%2==0,res)
print(res)
res=list(select(lambda x : (x,x**2), res))
print(res)
```

## Функция filter

**Функция filter** - *применяется указанную функцию к каждому элементу итерируемого объекта и возвращает те элементы, для которых функция вернула true*

### Пример 

```py
data=[x for x in range(10)]
res=list(filter(lambda x : x%2==0, data))
print(res)
```

### Улучшим код из прошлой задачи

```py
res=map(int,data)

res=filter(lambda x:x%2 ==0, res)

res=list(map(lambda x : (x, x**2), res))

print(res)
```

## Функция zip 
**Функция zip** *применяется к набору итерируемых объектов и возвращает итератор с кортежами из элементов входных данных. На выходе получаем набор данных, состоящий из элементов соотвестующему исходному набору данных*

### Пример

```py
users=['user1', 'user2', 'user3','user4', 'user5']
ids=[4,5,9,14,7]
data=list(zip(users, ids))
print(data)
```

### Функция zip пробегает по минимальному набору 

```py
users=['user1', 'user2', 'user3', 'user4', 'user5']
ids=[4,5,9,14,7]
salary=[111,222,333]
data=list(zip(users,ids,salary))
print(data)
```

## Файлы

Файлы в текстовом виде используются для :

* Хранения данных
* Передачи данных в клиент-серверных проектах
* Хранения конфигов
* Логирование действий

### Что нужно для работы с файлами

1. Завести переменную которая будет связана с этим текстовым файлом
2. Указать путь к файлу 
3. Указать в каком режиме мы будем работать мы будем работать с файлом 

### Варианты режима(мод):
1. a-откртие для добавления данных
* Позволяет дописывать что то в имеющийся файл
* Если попробуете дописать в несуществующий файл, то файл будет создан и в него начнется запись 
2. r-открытие для чтения данных :
* Позволяет читать данные из файла
* Если вы попробуете считать данные из несуществующего файла то будет ошибка
3. w-открытие для записи данных 
* Позволяет записывать данные и создавать файл, если его не существует 
### Миксированные режимы 
1. w+
* Позволяет открывать файл для записи и читать его 
* Если файла не существует он создается 
2. r+
* Позволяет открывать файл для чтения и дописывать в него
* Если файла не существует, программа выдаст ошибку 

#### Пример
```py
# Режим а
colors=['red', 'green', 'blue']

data=open('file.txt', 'a', encoding='utf-8')

data.writelines(colors) # Разделителей не будет

data.close()

# Режим w

with open('file.txt', 'w') as data:
    data.write('line 1\n')
    data.write('line 2\n')

# Режим r

path='file.txt'
data=open(path, 'r')
for line in data:
    print(line)
data.close()
```

### Модуль shutil 

Модуль shutil содержит набор функций высокого уровня для обработки файлов, групп файлов и папок. 

В частности позволяет копировать, перемещать и удалять файлы и папки 

Часто используют вместе с модулем os

Для работы с этим модулем его нужно импортировать в программу 
```py
import shutill
```

#### Базовые функции
1. `shutil.copyfile(src,dst)` - копирует содержимое (но не метаданные) файла src в dst
2. `shutil.copy(src,dst)` - копирует содержимое файла src в файл или папку dst
3. `shutil.rmtree(path)` - удаляет текующую директорию и под директорию ; path - должен указывать на директорию а не на символическую ссылку
